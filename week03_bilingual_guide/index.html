5步骤一 · 一次读完整个文件Step 1 · 01_read_file.php — read the whole file at once

目标：用最短的代码把一个文本文件全部读出来并显示，同时报告文件大小。
Goal: read an entire text file in one call, print it, and report its size.
01_read_file.php
<?php

$file = __DIR__ . '/data/data.txt';

$text = file_get_contents($file);

print "File content are \n" . $text;

$numBytes = filesize($file);

print "\nFilesize is " . $numBytes;

逐行说明 / Line-by-line

  • __DIR__ 是当前 PHP 文件所在绝对目录，用它拼路径可避免"换目录运行就找不到文件" / the absolute directory of the current file.
  • __DIR__ . '/data/data.txt' 拼出绝对路径（斜杠 / 要自己加）/ builds an absolute path — remember the slash.
  • file_get_contents($file) 一次把整个文件读成一个字符串，自动打开、自动关闭，不需要 fopen() / reads the whole file into one string and handles open/close for you.
  • print "…\n" . $text; 用 . 连接字符串；\n 只有在双引号里才会被解释成换行 / . concatenates; \n is parsed only inside double quotes.
  • filesize($file) 返回文件字节数 / returns the size in bytes.
  • 文件没有闭合标签 ?> —— 纯 PHP 文件建议省略，避免多余空白输出 / no closing ?>, which is recommended for pure-PHP files.

6步骤二 · 存在才读Step 2 · 02_read_file_exist.php — read only if it exists

目标：读文件前先用 file_exists() 判断，避免直接报 Warning；同时故意演示一个错误路径，理解绝对路径与相对路径的区别。
Goal: guard reads with file_exists(), and deliberately demo a wrong path to understand absolute vs. relative paths.
02_read_file_exist.php
<?php

$file1 = __DIR__ . '/data/data.txt';
$file2 = __DIR__ . 'data.txt';

if(file_exists($file1)){
    print 'File 1 exist';
    print file_get_contents($file1);
}

if(file_exists($file2)){
    print 'File 2 exist';
    print file_get_contents($file2);
}

逐行说明 / Line-by-line

  • $file1 是正确路径：项目目录/data/data.txt / a correct absolute path.
  • $file2 = __DIR__ . 'data.txt' 是故意写错的：少了 /data/ 子目录，实际指向不存在的 项目目录data.txt / intentionally wrong — the /data/ part is missing.
  • file_exists($path) 返回 true / false，常用于读、写、删除前的安全检查 / a boolean used as a safety check.
  • 只有 if 成立时才调用 file_get_contents()，所以不会出现 "Failed to open stream" 警告 / the read only runs when the check passes, so no warning appears.
  • 两个 print 之间没有 \n，所以 File 1 exist 会和文件内容连在一起 / no \n between the prints, so the output runs together.

运行与预期输出 / Run & expected 实测

Only File 1 appears: File 2's path does not exist, so file_exists() returns false and the second read is skipped. That is the value of checking first.

7步骤三 · 写入与追加Step 3 · 03_write_file.php — write and append

目标：用 heredoc 语法准备多行字符串，用 file_put_contents() 先覆盖写、再追加写。
Goal: prepare multi-line strings with heredoc, then overwrite and append with file_put_contents().
03_write_file.php
<?php

$file = __DIR__ . '/data/newfile.txt';

$content1 = <<< CONTENT
the cat
sat
on the mat

CONTENT;

file_put_contents($file,$content1);

$content2 = <<< CONTENT
the rat
spat
on the cat!
CONTENT;

file_put_contents($file,$content2,FILE_APPEND);

heredoc 的 4 条规则 / 4 rules of heredoc

  • <<< CONTENT 后面是自定义标识符，用来写多行字符串，里面的换行原样保留 / the identifier after <<< is your choice; line breaks are preserved exactly.
  • 结束标识符必须单独占一行（PHP 7.3+ 允许缩进，缩进会从字符串中移除）/ the closing identifier must be on its own line (PHP 7.3+ allows indentation, which is stripped).
  • 结束标识符后面的 ; 是语句结束符，不能漏 / the ; after it is the statement terminator.
  • 紧挨结束标识符的那一个换行不计入字符串。$content1 在 CONTENT; 前多留了一个空行，所以它以换行结尾；$content2 没有空行，所以不以换行结尾 / the newline immediately before the closing identifier is not part of the string.

file_put_contents 的两种行为 / Two behaviours

  • file_put_contents($file, $content1) 默认覆盖：原内容先被清空；文件不存在时自动创建 / default is overwrite; creates the file if missing.
  • 第三个参数 FILE_APPEND 表示追加到末尾、不覆盖 —— 本节课最重要的标志位 / FILE_APPEND appends instead of overwriting — the key flag of this lesson.
  • 这个脚本没有任何输出，它的成果在文件里；返回值是写入的字节数 / the script prints nothing; its result is in the file. The return value is the number of bytes written.

8步骤四 · 修 1 行，让 fileWrite() 真正能写Step 4 · Edit one line in inc/file_utility.php

目标：找到并修改 1 行，让写入函数生效。这是整个任务中唯一的"改错"环节。
Goal: locate and fix one line so the write function works. This is the only bug-fixing step.
打开 inc/file_utility.php，找到 fileWrite()（约第 55 行起），里面有这一行：
Open inc/file_utility.php, find fileWrite() (from about line 55), and look at this line:
inc/file_utility.php · 第 57 行 / line 57
// 改前 / before
$fh = fopen($fileName, "r"); // change to ab next

// 改后 / after
$fh = fopen($fileName, "a"); // change to ab next

为什么 / Why — fopen 模式对照表 / mode reference

模式 Mode含义 Meaning能读 Read能写 Write文件不存在时 If missing指针 Pointer
r只读 / read only✔✘失败 / fails开头 / start
r+读写 / read + write✔✔失败 / fails开头 / start
w只写，清空 / write, truncates✘✔自动创建 / creates开头 / start
w+读写，清空 / read + write, truncates✔✔自动创建 / creates开头 / start
a追加 / append✘✔自动创建 / creates末尾 / end
a+读 + 追加 / read + append✔✔自动创建 / creates末尾 / end
x / x+独占创建（已存在则失败）/ exclusive create✘ / ✔✔只在不存在时创建 / creates only if absent开头 / start

在 "r"（只读）句柄上调用 fwrite() 会失败，PHP 会提示：

PHP Notice: fwrite(): Write of 18 bytes failed with errno=9 Bad file descriptor

因为 fwrite() 返回 false，if (! fwrite(...)) 成立，于是代码主动抛出异常，输出 Error (File: .../file_utility.php, line 60): Could not open the file for writing!。源码里的注释 // why the exception was raised? bcause the file was opened for reading! 已经给出答案。

改成 "a" 后 fwrite() 成功，且原有内容不被覆盖 —— 正好符合 04 里"给 users.txt 增加一条记录"的需求。

Calling fwrite() on a "r" (read-only) handle fails with:

PHP Notice: fwrite(): Write of 18 bytes failed with errno=9 Bad file descriptor

Since fwrite() returns false, if (! fwrite(...)) is true and your own exception is thrown: Error (File: .../file_utility.php, line 60): Could not open the file for writing!. The in-code comment already gives the answer.

With "a", fwrite() succeeds and existing data is preserved — exactly what 04 needs.

提示 / Tip

"ab" 里的 b 表示二进制模式，在 Windows 上更安全；macOS/Linux 上 "a" 与 "ab" 效果相同。

The b in "ab" means binary mode (safer on Windows, equivalent on macOS/Linux).

改前 / 改后对比 实测

改前（"r"）：运行 04 后 users.txt 毫无变化，并输出上面的 Notice 与 Error。
改后（"a"）：users.txt 末尾新增 john\tjohn@doe.com（Tab 分隔），文件从 44 字节 变成 62 字节。
Before ("r"): after running 04, users.txt is unchanged and the Notice/Error lines appear.
After ("a"): a new line john\tjohn@doe.com is appended — the file grows from 44 to 62 bytes.

9步骤五 · 把工具箱拼装起来Step 5 · 04_file_read_write.php — glue it all together

目标：引入工具箱，把 4 个函数按"读数组 → 逐行读 → 读 CSV → 追加写入"的顺序调用一次。
Goal: include the toolbox and call all four functions in order.
04_file_read_write.php
<?php

require_once 'inc/file_utility.php';

// read the file as an array
$file = 'data/users.txt';
readArray($file);

// read using file_exist() and fgets()
$file = 'data/orders.txt';
readData($file);

// read using file_exist() and fgetcsv()
$file = 'data/orders.csv';
readCSV($file);

// write a new entry to users.txt
$file = 'data/users.txt';
$data = "\njohn\tjohn@doe.com";

fileWrite($file,$data);

逐行说明 / Line-by-line

  • require_once 'inc/file_utility.php'; 保证工具箱只引入一次，避免"函数重复定义"的致命错误 / includes the toolbox exactly once.
  • 这里的路径是相对路径（相对运行时的工作目录），所以必须在项目根目录执行 / these are relative paths, so run from the project root.
  • $data = "\njohn\tjohn@doe.com"; 以换行开头（原文件最后一行没有换行符，先补一个才不会接在同一行后）；\t 是 Tab，因为 readArray() 用 explode("\t") 切分，必须用 Tab，不能用空格。
  • In English: the string starts with \n to begin a new line, and uses \t because readArray() splits on tab — a space will not work.

四次调用对照 / The four calls

调用 Call函数 Function内部机制 Internals输出 Output
readArray('data/users.txt')readArray() file() 一次读成数组 → foreach → explode("\t") → list($name,$email) → trim() 去行尾换行 每行一个 mailto: 链接
readData('data/orders.txt')readData() → openFile() file_exists() → fopen('r') → while(!feof) echo fgets() → fclose() 原样文本 / raw text

13加练题目Extension exercises

  1. 数行数 / Count lines. 写 05_count_lines.php，输出 data/orders.txt 的总行数（提示：file() + count()）。
  2. 安全的表格 / Safer table. 给 readCSV() 加 if(!$fh) return;，补上漏掉的 </table>，并用 htmlspecialchars() 处理单元格内容，防止 HTML 注入。
  3. 更好的 CSV 表格 / Better CSV table. 第一行改成表头 <th>，其余行用 <td>（提示：加一个计数器变量）。
  4. 创建新文件的函数 / Exclusive create. 给 inc/file_utility.php 追加 writeNewFile($fileName, $str)：文件不存在时用 "w" 模式创建并写入，返回写入字节数；已存在时阻止覆盖并提示。
  5. 加锁写入 / Locked append. 用 file_put_contents($f, $s, FILE_APPEND | LOCK_EX) 追加一行，并解释多用户环境下 LOCK_EX 的作用。
  6. 返回数据而不是直接输出 / Return, don't echo. 复制 readCSV() 为 getCSV($fileName)，把 echo 改成累积字符串并 return，体会"函数返回数据、页面负责显示"的分离设计。
